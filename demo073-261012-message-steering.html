PRD 交互体验

PRD v0.2.5 · Web · 单文件离线演示
体验路径与 PRD 对照
  1. 先悬停消息左侧排队图标，查看“排队中 等待数 / 总数”。总数包含生成中的任务。
  2. 点击任意一条右侧 ↵，仅发送这一条；垃圾桶保持原有删除操作。
  3. 观察加载原位、成功入会话；工具期间等待工具结束，再应用新指令。
  4. 失败原位保留，可再次点击 ↵；服务异常结束任务但不自动汇总。
  5. 点击输入区停止按钮，查看未完成任务、队列和待插入消息汇总。
  6. 右侧控件仅用于演示场景，不属于产品页面。本 Demo 不验证真实模型、服务或移动端。
